# AGENTS.md

## Cursor Cloud specific instructions

Super Sniper 8D is a single **Godot 4.4** game project (no web/server backend). The
engine is the only external dependency.

### Engine
- Godot **4.4.1-stable** (Standard build, not Mono) is installed at `/usr/local/bin/godot`.
- The `.godot/` folder is gitignored and is regenerated by importing (see below); never commit it.

### Common commands (run from repo root `/workspace`)
- Import/refresh assets (regenerates `.godot/`): `godot --headless --import`
- Run the game (windowed, needs a display): `godot --path /workspace`
- Open the editor: `godot --editor --path /workspace`
- Headless smoke test (loads the main scene, then quits): `godot --headless --quit-after 120`

### Notes
- The startup scene is `scenes/common/Main.tscn`, which instances `scenes/menu/MainMenu.tscn`.
- There is no lint tool or automated test framework configured in this repo (pure GDScript);
  "testing" currently means running the game and verifying the main menu renders and its
  buttons work. Only the Exit button is wired to an action (`get_tree().quit()`); Play/Weapons/Settings
  are placeholders for later milestones.
- Running `godot --path /workspace` in a fresh checkout also triggers an import on first launch,
  but running `godot --headless --import` first avoids a slow first frame.
- To view the game GUI, launch `godot --path /workspace` from a desktop terminal (it needs an X display).
